🔐 Random Password Generator

 📌 Project Description

The Random Password Generator is a Python project that generates random passwords based on the user's preferences. Users can choose the password length and decide whether to include uppercase letters, numbers, and special characters.

 🎯 Objectives
* To learn Python programming.
* To understand conditional statements and loops.
* To practise taking input from users.
* To generate random passwords using Python.
* To understand the importance of strong passwords.

 ✨ Features
* Custom password length between 8 and 64 characters.
* Optional uppercase letters.
* Optional numbers.
* Optional special characters.
* Secure random character selection.
* Input validation.

 🛠️ Technologies Used
* Python
* Google Colab
* `secrets` module
* `string` module

 ▶️ How to Run
1. Open `Random_Password_Generator.ipynb`.
2. Open the notebook in Google Colab.
3. Run the code cells in order.
4. Enter the desired password length.
5. Select the character types to include.
6. View the generated password.

 📚 Concepts Used
* Variables and strings
* User input
* Conditional statements
* Loops
* Exception handling
* Python modules

 ✅ Conclusion
This project demonstrates how Python can be used to generate random passwords according to user preferences. It provides practical experience with basic programming concepts and secure random character selection.
